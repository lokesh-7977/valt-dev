# shadcn/ui on Tailwind CSS v4 (VALT)

## Setup (once)

```bash
cd apps/web
pnpm dlx shadcn@latest init        # writes components.json, lib/utils.ts, updates globals.css
pnpm dlx shadcn@latest add button card input textarea label badge skeleton alert-dialog sonner
```

- `components.json` aliases must match `tsconfig.json` paths (`@/components`, `@/lib/utils`).
- `init` tries to rewrite `src/app/globals.css`. **Keep ours.** It already defines every shadcn
  variable with VALT's values (`design-system/valt/MASTER.md`), plus type roles, elevations, motion,
  and the `material` utility. Commit before `init`, then restore `globals.css` from git and keep
  only additions you actually need.
- Commit everything `add` generates. Components in `components/ui/` are our code; edit them.
- Updating a component later: re-run `add <name>` with `--overwrite` on a clean tree and review the
  diff — local edits will be overwritten.

## `cn()`

```ts
// apps/web/src/lib/utils.ts  (generated by init)
import { clsx, type ClassValue } from "clsx";
import { twMerge } from "tailwind-merge";

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
```

Always accept and merge `className` so callers can adjust layout:

```tsx
export function StatusBadge({ status, className }: { status: RunStatus; className?: string }) {
  return (
    <Badge variant={status === "error" ? "destructive" : "secondary"} className={cn("gap-1", className)}>
      {status === "error" ? <XCircle aria-hidden className="size-3" /> : <CheckCircle aria-hidden className="size-3" />}
      {status}
    </Badge>
  );
}
```

(Icon + text, never colour alone.)

## Dark mode

shadcn's CSS uses a `.dark` class. Two options:

1. **Follow the OS only** (current behaviour): replace the `.dark { … }` selector with
   `@media (prefers-color-scheme: dark) { :root { … } }`.
2. **User toggle** (recommended once there's a settings UI): `pnpm add next-themes`, wrap
   `<Providers>` in `<ThemeProvider attribute="class" defaultTheme="system" enableSystem>`, and add
   `suppressHydrationWarning` to `<html>`.

## Custom tokens

Add brand or status colours as variables, then expose them to Tailwind:

```css
:root { --success: oklch(0.62 0.17 150); }
.dark { --success: oklch(0.72 0.17 150); }

@theme inline {
  --color-success: var(--success);
}
```

Now `bg-success`, `text-success` work and follow the theme.

## Variants with cva

```tsx
import { cva, type VariantProps } from "class-variance-authority";

const stepVariants = cva("flex items-center gap-2 text-sm", {
  variants: {
    state: {
      pending: "text-muted-foreground",
      running: "text-foreground",
      done: "text-success",
      failed: "text-destructive",
    },
  },
  defaultVariants: { state: "pending" },
});

export function Step({ state, className, ...props }: React.ComponentProps<"li"> & VariantProps<typeof stepVariants>) {
  return <li className={cn(stepVariants({ state }), className)} {...props} />;
}
```

## Migrating an existing component — `health-card.tsx`

```tsx
import { Card, CardContent, CardHeader, CardTitle } from "@/components/ui/card";
import { getHealth } from "@/lib/api";

export async function HealthCard() {
  let body: string;
  try {
    const health = await getHealth();
    body = `${health.status} · ${health.service} v${health.version}`;
  } catch {
    body = "unreachable — is the FastAPI service running on :8000?";
  }

  return (
    <Card>
      <CardHeader>
        <CardTitle className="text-xs font-medium uppercase tracking-wide text-muted-foreground">
          API health
        </CardTitle>
      </CardHeader>
      <CardContent className="font-mono text-sm">{body}</CardContent>
    </Card>
  );
}
```

`border-black/10 … dark:border-white/15` and `opacity-60` become theme tokens (`border` from
`Card`, `text-muted-foreground`).

## Forms: react-hook-form + zod + shadcn form primitives

```bash
pnpm dlx shadcn@latest add form     # or `field`, whichever the current CLI provides
pnpm --filter @valt/web add react-hook-form zod @hookform/resolvers
```

```tsx
"use client";

import { zodResolver } from "@hookform/resolvers/zod";
import { useForm } from "react-hook-form";
import { z } from "zod";
import { Button } from "@/components/ui/button";
import { Form, FormControl, FormField, FormItem, FormLabel, FormMessage } from "@/components/ui/form";
import { Input } from "@/components/ui/input";
import { useCreateItem } from "@/lib/queries/items";

// mirrors ItemCreate in schemas.py (name: 1–200 chars)
const schema = z.object({ name: z.string().min(1, "Required").max(200) });

export function NewItemForm() {
  const form = useForm<z.infer<typeof schema>>({ resolver: zodResolver(schema), defaultValues: { name: "" } });
  const createItem = useCreateItem();

  return (
    <Form {...form}>
      <form onSubmit={form.handleSubmit((v) => createItem.mutate(v, { onSuccess: () => form.reset() }))} className="space-y-4">
        <FormField
          control={form.control}
          name="name"
          render={({ field }) => (
            <FormItem>
              <FormLabel>Name</FormLabel>
              <FormControl><Input {...field} /></FormControl>
              <FormMessage />
            </FormItem>
          )}
        />
        <Button type="submit" disabled={createItem.isPending}>Create</Button>
      </form>
    </Form>
  );
}
```

The server still validates (Pydantic); client validation is for UX only. Use plain `useState` for
tiny forms (1–2 fields, no validation), like the chat input.

## DataTable: shadcn Table + TanStack Table

```bash
pnpm dlx shadcn@latest add table
pnpm --filter @valt/web add @tanstack/react-table
```

```tsx
"use client";

import {
  type ColumnDef,
  flexRender,
  getCoreRowModel,
  getSortedRowModel,
  type SortingState,
  useReactTable,
} from "@tanstack/react-table";
import { useState } from "react";
import { Table, TableBody, TableCell, TableHead, TableHeader, TableRow } from "@/components/ui/table";

export function DataTable<T>({ columns, data }: { columns: ColumnDef<T>[]; data: T[] }) {
  const [sorting, setSorting] = useState<SortingState>([]);
  const table = useReactTable({
    data,
    columns,
    state: { sorting },
    onSortingChange: setSorting,
    getCoreRowModel: getCoreRowModel(),
    getSortedRowModel: getSortedRowModel(),
  });

  return (
    <div className="rounded-md border">
      <Table>
        <TableHeader>
          {table.getHeaderGroups().map((hg) => (
            <TableRow key={hg.id}>
              {hg.headers.map((h) => (
                <TableHead key={h.id} aria-sort={h.column.getIsSorted() === "asc" ? "ascending" : h.column.getIsSorted() === "desc" ? "descending" : "none"}>
                  {h.isPlaceholder ? null : flexRender(h.column.columnDef.header, h.getContext())}
                </TableHead>
              ))}
            </TableRow>
          ))}
        </TableHeader>
        <TableBody>
          {table.getRowModel().rows.length ? (
            table.getRowModel().rows.map((row) => (
              <TableRow key={row.id}>
                {row.getVisibleCells().map((cell) => (
                  <TableCell key={cell.id}>{flexRender(cell.column.columnDef.cell, cell.getContext())}</TableCell>
                ))}
              </TableRow>
            ))
          ) : (
            <TableRow>
              <TableCell colSpan={columns.length} className="h-24 text-center text-muted-foreground">
                No results.
              </TableCell>
            </TableRow>
          )}
        </TableBody>
      </Table>
    </div>
  );
}
```

Feed `data` from a TanStack Query hook. For server-side sorting/pagination, set
`manualSorting`/`manualPagination` and put the sort/cursor in the query key and URL.
For >1k rows rendered at once, add `@tanstack/react-virtual`.

## Toasts

Use `sonner` (`add sonner`, mount `<Toaster />` once in `Providers`). Toasts are for transient
confirmations; errors the user must act on stay inline with `role="alert"`.
